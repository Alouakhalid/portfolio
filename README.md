## 📦 How to Deploy to GitHub Pages (2 Minutes)

### Option A: Create a New Repo on GitHub
1. Go to [GitHub New Repository](https://github.com/new).
2. Name it `portfolio` (or `Alouakhalid.github.io` for root domain).
3. Set visibility to **Public**.
4. In your terminal, run:
   ```bash
   git remote add origin https://github.com/Alouakhalid/portfolio.git
   git branch -M main
   git push -u origin main
   ```
5. Go to your repository on GitHub:
   - Click **Settings** → **Pages** (on the left sidebar).
   - Under **Build and deployment**:
     - Source: **Deploy from a branch**
     - Branch: **`main`** / Folder: **`/ (root)`**
   - Click **Save**.
6. Your site will immediately be live at:
   ```
   https://alouakhalid.github.io/portfolio/
   ```
